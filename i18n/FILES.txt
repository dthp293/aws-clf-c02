i18n file layout (same names for every language: en, ja)
=========================================================
i18n/<lang>/ui.js        L.ui      (UI strings; keys = same as i18n/en/ui.js)
i18n/<lang>/data.js      L.domains, L.glossary, L.services, L.lessons
i18n/<lang>/q-1.js       L.q for question ids (practice + mock-exam pool; any q-N.js file can hold any id)
i18n/<lang>/q-2.js       L.q for question ids
i18n/<lang>/q-3.js       L.q for question ids
i18n/<lang>/q-4.js       L.q for question ids
i18n/<lang>/q-5.js       L.q for question ids
i18n/<lang>/q-6.js       L.q for question ids
i18n/<lang>/q-7.js       L.q for question ids
i18n/<lang>/q-8.js       L.q for question ids
i18n/<lang>/course-a.js  L.course for lessons defined in content/lessons/course-a.js
i18n/<lang>/course-b.js  ... content/lessons/course-b.js
i18n/<lang>/course-c.js  ... content/lessons/course-c.js
i18n/<lang>/course-d.js  ... content/lessons/course-d.js
i18n/<lang>/course-e.js  ... content/lessons/course-e.js
i18n/<lang>/course-f.js  ... content/lessons/course-f.js

Total per language: 16 files. The loader in js/main.js (list I18N_FILES in js/i18n.js) loads exactly these names
(it does not matter which q-N.js file an id lives in, as long as all 552 ids exist).
L.q[id] fields: exp, why[] (all languages); ja also has q (question stem) and opts[] (options, same order as the source opts)
  because CLF-C02 is offered in Japanese; en shows the original English question.
L.course[id] fields: title, goals[], html, summary[], terms[[term, meaning]]
  terms: same length/order as the VI lesson's terms; element [0] = the English term (unchanged),
  [1] = meaning in <lang> (VI has e.g. ["Server","máy chủ"]).
ui.js keys: copy from i18n/en/ui.js (written by the EN agent; keys are stable once the file exists).
